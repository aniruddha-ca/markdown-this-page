# Markdown This Page

A Chrome extension (Manifest V3) that converts the current webpage to Markdown — main content only — then lets you preview, edit, copy, or download the `.md` file.

## Features

- **Main content extraction** — strips headers, navs, sidebars, footers, and other page chrome using [Mozilla Readability](https://github.com/mozilla/readability) (the Firefox reader-mode algorithm), with a selector-based fallback for pages Readability can't parse.
- **GFM support** — tables, task lists, and `~~strikethrough~~` via the Turndown GFM plugin.
- **Live preview** — split/edit/preview views, rendered with `marked` and sanitized with DOMPurify.
- **Editable output** — tweak the Markdown before copying or downloading.
- **Relative URL resolution** — `href`, `src`, and `srcset` are rewritten to absolute URLs against the page URL.
- **Copy or download** — one click, or `Ctrl/Cmd+S` in the editor.
- **Zero build step** — plain HTML/JS/CSS, no dependencies to install.

## Install (load unpacked)

1. Open `chrome://extensions`.
2. Enable **Developer mode** (top right).
3. Click **Load unpacked** and select this folder.
4. Pin the "Markdown This Page" icon to the toolbar.

## Usage

1. Open any normal web page (not a browser-internal page like `chrome://`).
2. Click the extension icon, or press the shortcut:
   - **Windows/Linux:** `Ctrl+Shift+M`
   - **macOS:** `Cmd+Shift+Y`
3. A new tab opens with the extracted Markdown and a live preview.
4. Edit if needed, then **Copy** or **Download .md**.

## How it works

```
Click / shortcut
      │
      ▼
1. CAPTURE   background.js — chrome.scripting.executeScript clones the page DOM,
      │       strips script/iframe/meta tags, and sends {title, url, html}
      │       through chrome.storage.session
      ▼
2. EDITOR    editor.html + editor.js open and read the capture
      ▼
3. CONVERT   toMarkdown(html, url)
      │       ├─ absolutize()         resolve relative href/src/srcset
      │       ├─ extractMainContent() Readability → article only
      │       │                        (fallback: remove nav/aside/footer/sidebar/header)
      │       └─ Turndown             DOM → Markdown (GFM + fixed style options)
      ▼
4. OUTPUT    textarea + live preview → Copy / Download
```

## Project structure

```
manifest.json                 MV3 manifest (permissions, icon, shortcut)
background.js                 Service worker: captures the page DOM
editor.html / .js / .css      Converter UI: preview, edit, copy, download
lib/turndown.js               HTML → Markdown engine (MIT)
lib/turndown-plugin-gfm.js    GFM tables, task lists, strikethrough (MIT)
lib/readability.js            Main-content extraction (Apache-2.0)
lib/marked.min.js             Markdown → HTML for preview only (MIT)
lib/purify.min.js             Sanitizes preview HTML (MPL-2.0)
icons/                        Extension icons (generated by tools/make_icons.py)
```

## Permissions

| Permission  | Why |
|-------------|-----|
| `activeTab` | Access the current tab when you trigger conversion |
| `scripting` | Inject the DOM-capture function |
| `storage`   | Pass the captured page to the editor tab (session storage only) |

Nothing is sent anywhere — the extension has no network access and no remote code.

## Notes

- Very large pages may exceed the `chrome.storage.session` quota; the extension reports this instead of failing silently.
- Turndown style options (ATX headings, fenced code, `-` bullets, inlined links) are hardcoded in `toMarkdown()` in `editor.js`.
